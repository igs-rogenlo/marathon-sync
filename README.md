# 馬拉松表單同步排程

跑團的 Strava 紀錄要自動寫進 Google 試算表的填單區。

這個倉庫的用途很單純：**每 30 分鐘叫一次試算表那邊的同步程式**，
由試算表自己去 Strava 抓每位跑者的新紀錄，再寫進表單。
中間不經過任何需要付費的雲端主機。

## 需要設定的兩個密鑰（Settings → Secrets and variables → Actions）

| 名稱 | 內容 |
| --- | --- |
| `GAS_EXEC_URL` | 試算表程式的網址（結尾是 `/exec`） |
| `GAS_TOKEN` | 呼叫同步用的通行碼 |

## 手動補資料

到 Actions 分頁 → 「馬拉松表單同步」 → Run workflow，
「往回補幾天的紀錄」填天數（例如漏了一週就填 `8`）。
重複的紀錄會自動略過，不會重複計算。

## 說明

- 排程時間由 GitHub 決定，延遲幾分鐘是正常的；每次都會往回看 3 天，
  所以就算某一輪沒跑到，下一輪也會補上。
- 每天凌晨會自動留一筆心跳紀錄，避免 GitHub 因為「倉庫太久沒動靜」
  把排程自動關掉。
